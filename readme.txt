─────────────────────────────────────────────────────────────────────
◆ゲームの起動
─────────────────────────────────────────────────────────────────────

ゲームフォルダ内の「Game.exe」をダブルクリックして実行してください。

─────────────────────────────────────────────────────────────────────
◆セーブデータ移行方法
─────────────────────────────────────────────────────────────────────

体験版や過去バージョンからのセーブデータを移行するには、
旧バージョンのゲームフォルダ内にある「save」フォルダを新しいバージョンの同じフォルダにコピーしてください。

─────────────────────────────────────────────────────────────────────
◆オープニング動画について
─────────────────────────────────────────────────────────────────────

ご使用の端末によっては処理が完了せず、ゲームがクラッシュしてしまう場合が御座います。
その場合は選択肢にて「オープニング動画を再生しますか？」を「いいえ」と選択お願い致します。

─────────────────────────────────────────────────────────────────────
◆設定について
─────────────────────────────────────────────────────────────────────

・ゲームが重い場合、戦闘エフェクトの数値、パーティクルの設定を「最高」～「最低」の中から設定し、調整お願い致します。(デフォルトでは「最高」になっています)
・戦闘の処理が遅いと感じる場合、戦闘速度と戦闘アニメーションの高速化を設定お願い致します。
　
─────────────────────────────────────────────────────────────────────
◆動作環境
─────────────────────────────────────────────────────────────────────

本作品を快適にプレイするための推奨動作環境は以下の通りです。（RPGツクール公式サイトより）

OS: Windows 8.1/10 (64bit) または macOS 10.13以降
CPU: Intel Core i3-4340相当以上（2013年 第四世代）
メモリ: 8GB以上
HDD: 空き容量8GB以上
グラフィックス: OpenGL対応 VRAM 1 GB以上
ディスプレイ: 解像度1280×768以上
